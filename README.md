####################
Photoelectric Effect (dataMain and dataFunctions belong to this)

I have included the lab report I submitted with this code. The lab report itself is completed in Latex and explains the purpose of the code. In short, it is designed to estimate the value of the stopping voltage in a phototube for different frequencies of light. The code estimates a high and low voltage regions and performs a linear regression for each. Uncertainties are propagated via the bootstrap method.
